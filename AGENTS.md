# Surf project

Use `CLAUDE.md` as the repository instruction source.

For trip decisions, coastline discovery, seasonal weather or flat-spell
analysis, bathymetry, backtesting, KMZ output, MCP/mobile access, or swell
alerts, read `docs/ARCHITECTURE.md` first. It defines the code layout, the
product model and the shared evidence loop.

Before starting work — status, "where are we", resuming, or touching spots,
scoring or an endpoint — read `.codex/skills/surf-brief/SKILL.md` and follow it.
It is a symlink to `.claude/skills/surf-brief/SKILL.md`; one file, both agents.
